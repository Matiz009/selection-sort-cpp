# Selection Sort (C++)

Selection sort on an array in C++.

## Features

- Sorts a hard-coded 7-element array into ascending order using selection sort
- Prints the sorted array

## Tech stack

C++

## Getting started

```bash
git clone https://github.com/Matiz009/selection-sort-cpp.git
cd selection-sort-cpp
g++ "selct-sort.cpp" -o selct-sort && ./selct-sort
```

## Project structure

```
selct-sort.cpp   Source code
selct-sort.exe   Old Windows build
```
